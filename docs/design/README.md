# Design notes

`docs/product.md` is the spec. A note stays here only while it is not an acceptance criterion.

When a note becomes player-facing behavior, add the criterion to `docs/product.md` and implement that criterion. Leave the rejected alternative in `docs/decisions/` when the choice is hard to reverse.
